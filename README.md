# PPB Modul 6

Jalankan backend dalam mode development dari folder utama:

```sh
npm run dev
```

Perintah tersebut meneruskan ke script development di folder `backend`.

## Aplikasi mobile

Jalankan aplikasi Expo dari folder `app`:

```sh
cd app
npm start
```

Aplikasi LiveTemp menyediakan splash screen, monitoring suhu dan kelembapan
dengan pagination riwayat, pengaturan ambang batas, serta profil Kelompok 20.
